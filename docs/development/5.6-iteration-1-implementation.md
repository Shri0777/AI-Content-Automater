## 5. DATABASE SCHEMA

### 5.1 UserProfile Table

```sql
CREATE TABLE users_userprofile (
    id BIGSERIAL PRIMARY KEY,
    user_id INTEGER NOT NULL UNIQUE REFERENCES auth_user(id) ON DELETE CASCADE,
    display_name VARCHAR(100),
    bio TEXT,
    timezone VARCHAR(50) DEFAULT 'UTC',
    created_at TIMESTAMP NOT NULL,
    updated_at TIMESTAMP NOT NULL
);

CREATE INDEX users_userprofile_user_id ON users_userprofile(user_id);
```

### 5.2 Content Table

```sql
CREATE TABLE content (
    id BIGSERIAL PRIMARY KEY,
    owner_id INTEGER NOT NULL REFERENCES auth_user(id) ON DELETE CASCADE,
    title VARCHAR(255) NOT NULL,
    topic VARCHAR(500),
    description TEXT,
    lifecycle_state VARCHAR(50) NOT NULL DEFAULT 'draft',
    current_version_id BIGINT REFERENCES content_version(id) ON DELETE SET NULL,
    created_at TIMESTAMP NOT NULL,
    updated_at TIMESTAMP NOT NULL,
    deleted_at TIMESTAMP
);

CREATE INDEX content_owner_id ON content(owner_id);
CREATE INDEX content_lifecycle_state ON content(lifecycle_state);
CREATE INDEX content_created_at ON content(created_at);
```

### 5.3 ContentVersion Table

```sql
CREATE TABLE content_version (
    id BIGSERIAL PRIMARY KEY,
    content_id BIGINT NOT NULL REFERENCES content(id) ON DELETE CASCADE,
    version_number INTEGER NOT NULL,
    content_text TEXT,
    created_by_id INTEGER NOT NULL REFERENCES auth_user(id) ON DELETE CASCADE,
    created_at TIMESTAMP NOT NULL,
    change_summary TEXT,
    is_approved BOOLEAN DEFAULT FALSE,
    UNIQUE (content_id, version_number)
);

CREATE INDEX content_version_content_id ON content_version(content_id);
CREATE INDEX content_version_content_created ON content_version(content_id, created_at);
```

**Relationships:**
- User → UserProfile (1:1)
- User → Content (1:Many, owner)
- User → ContentVersion (1:Many, created_by)
- Content → ContentVersion (1:Many, versions)
- Content → ContentVersion (1:1, current_version)

## 7. AUTHORIZATION IMPLEMENTATION

### 7.1 Ownership Decorator

```python
# content/authorization.py
from functools import wraps
from django.shortcuts import get_object_or_404
from django.http import HttpResponseForbidden
from .models import Content

def user_owns_content(view_func):
    @wraps(view_func)
    def wrapper(request, pk, *args, **kwargs):
        content = get_object_or_404(Content, pk=pk)
        if content.owner != request.user:
            return HttpResponseForbidden("You don't have permission to access this content.")
        return view_func(request, pk, *args, **kwargs)
    return wrapper
```

**Usage:**
```python
@login_required
@user_owns_content
def content_detail(request, pk):
    # User is guaranteed to own this content
    ...
```

### 7.2 Authorization Rules Enforced

1. **Authentication Required**
   - All content operations require `@login_required`
   - Unauthenticated users redirected to login

2. **Ownership Verification**
   - Read, update, delete operations check ownership
   - 403 Forbidden if user doesn't own content
   - No information leakage (404 before ownership check)

3. **List Filtering**
   - `Content.objects.filter(owner=request.user)`
   - Users only see their own content
   - No cross-user visibility

4. **Creation Assignment**
   - `content.owner = request.user` on create
   - Owner assigned from authenticated user
   - Cannot create content for other users
