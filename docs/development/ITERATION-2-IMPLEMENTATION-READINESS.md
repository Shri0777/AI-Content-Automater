## MIGRATION STRATEGY

### Migration Sequence

1. **0002_version_immutability.py**
   - Add PostgreSQL trigger
   - Prevents UPDATE on content_version
   - Reversible

2. **0003_research_models.py**
   - Create Research table
   - Create ResearchContentAssociation table
   - Add Content.research_items M2M

3. **0004_research_profiles.py**
   - Create ResearchProfile table
   - Create ContentCreationRequest table

4. **0005_research_enhancements.py**
   - Add RSS/GNews fields to Research
   - Add indexes for performance

### Safety Measures

**All non-destructive:**
- No data deletion
- No column drops
- All new fields nullable or defaulted
- Safe rollback at any point

### Rollback Commands

```bash
# Rollback to specific migration
python manage.py migrate content 0004_research_profiles
python manage.py migrate content 0003_research_models
python manage.py migrate content 0002_version_immutability
python manage.py migrate content 0001_initial

# Check current state
python manage.py showmigrations content
```
