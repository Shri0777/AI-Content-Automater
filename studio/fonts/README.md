# Fonts

`InterVariable.ttf` is [Inter](https://github.com/rsms/inter) 4.1 by Rasmus
Andersson and the Inter Project Authors, unmodified. It is used for all text
on the slides (`studio/posters.py`, `font_of()`), in its Regular and Bold
weights. Pillow's own built-in font has no accented letters, dashes or
currency signs other than "$", so names such as "José" or prices in euros
would be drawn as boxes.

Inter is licensed under the SIL Open Font License 1.1, which allows it to be
bundled with this app; the licence is in `OFL.txt`.
